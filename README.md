# Instagram Clone 📸

یه کلون نسبتاً کامل از اینستاگرام با قابلیت‌های اصلی:

- پست گذاشتن
- استوری
- لایک و کامنت
- چت واقعی (تقریبی)
- پروفایل کاربر

**ساخته شده توسط امیرحسین بخشی**

---

## تکنولوژی‌ها

- Next.js / React
- TypeScript
- احتمالاً Tailwind یا CSS Modules
- APIهای مختلف برای دیتا

---

## اجرا

```bash
npm install
npm run dev
```

اگر نیاز به API Key داره (مثل Gemini)، توی `.env.local` بذار:

```
GEMINI_API_KEY=your_key_here
```
